Why restart instead of logout? GNOME Display Manager (GDM) starts at boot before any user logs in. When you log out, GDM keeps running in the background with its existing display server handles. A system restart is required for GDM and Mutter to parse updated udev rules and re-enumerate GPU display controllers.

Power Impact: When HDMI is enabled and driving an external monitor, the NVIDIA discrete GPU will stay awake in D0 mode (~10–15W base draw). Turning this off allows the dGPU to enter deep Runtime D3cold sleep (0W) on battery.

Compute & AI: Even when HDMI is disabled for power saving, CUDA, PyTorch, Ollama, Strata, and on-demand GPU offload (switcheroo-control / PRIME) continue to work normally.

Thunderbolt / USB-C: Type-C DisplayPort outputs are wired directly to the Intel integrated GPU and work at all times regardless of this setting.
